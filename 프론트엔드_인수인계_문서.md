# 프론트엔드 인수인계 문서

## 1. 프로젝트 개요

- 신사플라워 온라인 꽃집 플랫폼 (B2B 발주·수주 관리 및 정산 관리)
- 주요 역할: 주문/정산 화면 구현, API 연동, 상태 관리, 반응형 디자인

## 2. 개발 환경 & 실행

- **기술 스택**: Next.js 15, React 19, TypeScript 5, TailwindCSS 3
- **패키지 매니저**: Yarn 4 (Berry)
- **실행**: `yarn dev`
- **빌드**: `yarn build`
- 상세 내용은 README.md 참고

## 4. 상태 관리 & 데이터 흐름

- **Context API** (`shared/context/auth.context.tsx`) → 로그인/회원 정보 관리
- **React Hook Form** → 폼 상태 관리 (주문 폼, 회원가입 폼)
- **주문 검색 필터** → `features/order/context/order-search.context.tsx`에서 관리
- **API 통신** → `shared/lib/http/` 디렉토리의 클라이언트/서버 요청 함수 사용

## 5. 주요 페이지 구조

- **인증 페이지**: `/login`, `/register`
- **메인 대시보드**: `/` (DashBoard.tsx)
- **주문 관리**:
  - `/orders/create` → 발주 생성
  - `/orders/purchase` → 전체 발주 리스트
  - `/orders/sales` → 전체 수주 리스트
  - `/orders/pending` → 미확인 주문 리스트
  - `/orders/canceled` → 취소 주문 리스트
- **회원 관리**: `/members` → 회원 검색
- **프로필 관리**: `/edit-profile`, `/my/profile`

## 6. API 연동

- **인증 API**: `/api/auth/*` (로그인, 회원가입, 사용자 정보)
- **주문 API**: `/api/orders/*` (주문 CRUD, 월별 조회, 요약)
- **HTTP 클라이언트**: Axios 기반, `shared/lib/http/`에서 관리
- **서버 사이드**: `features/auth/server/auth.server.ts`에서 서버 사이드 인증 처리
- 상세 내용은 API 명세서 참고

## 7. 스타일링

- **TailwindCSS** → 유틸리티 기반 스타일링
- **커스텀 CSS**:
  - `shared/styles/globals.css` → 전역 스타일
  - `shared/styles/fonts.css` → 폰트 설정
- **모듈 CSS**: `ProductPriceTable.module.css`, `RegionSelector.module.css`

## 10. 폴더 구조

```
src/
├── app/                   # Next.js App Router
│   ├── (auth-layout)/     # 인증 레이아웃
│   └── (base-layout)/     # 기본 레이아웃
├── features/              # 기능별 모듈
│   ├── auth/              # 인증 관련
│   ├── order/             # 주문 관련
│   ├── product/           # 상품 관련
│   └── region/            # 지역 관련
└── shared/                # 공통 모듈
    ├── components/        # 공통 컴포넌트
    ├── context/           # Context API
    ├── hooks/             # 커스텀 훅
    ├── lib/               # 유틸리티 라이브러리
    ├── styles/            # 스타일 파일
    └── types/             # 타입 정의
```

## 11. 개발 가이드라인

- **컴포넌트**: 기능별로 `features/` 디렉토리에 모듈화
- **공통 컴포넌트**: `shared/components/`에 재사용 가능한 컴포넌트
- **타입 정의**: `shared/types/`에 공통 타입, 각 기능별 `types/`에 특화 타입
- **스타일링**: TailwindCSS 우선, 필요시 커스텀 CSS
- **폼 관리**: React Hook Form 사용
- **API 통신**: `shared/lib/http/`의 클라이언트 함수 사용
